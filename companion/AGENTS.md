# Rift Warehouse Scanner
- Preserve cloud inventory, serials, batches, approvals, learning, orders and locations.
- Local records are drafts, not stock. Never silently promote native match scores to cloud confidence.
- Native runtime version has its own index identity; do not reuse OpenCV.js feature caches without verified compatibility.
- Keep secrets in macOS Keychain; never commit tokens, scans, local SQLite files or caches.
- Exact host/origin checks and device revocation are mandatory. No global auth exemptions.
- Retries must retain local UUIDs, device identity and file identity. Test lost acknowledgments.
- Folder intake must not modify originals or reorder physical scans.
- Run Python unit tests plus repository npm test for cloud changes. Be explicit about lack of macOS acceptance testing.
